# Scrapline – Releases

Installer für **Scrapline**, ein postapokalyptisches Koop-Survival-Spiel für Windows (in Entwicklung).
Dieses Repository enthält nur die Installer und das Update-Manifest, keinen Quellcode.

- Neuester Installer: [`Scrapline-0.4.1-Setup.exe`](Scrapline-0.4.1-Setup.exe)
- `latest.json` liest der Updater im Spiel (Hauptmenü → „Update verfügbar“).
- Eine neue Version über eine alte installieren behält Spielstände und Einstellungen (`%APPDATA%\Scrapline`).
- Der Installer ist nicht signiert; Windows SmartScreen kann warnen („Weitere Informationen“ → „Trotzdem ausführen“).
